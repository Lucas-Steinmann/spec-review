# Specification overview

No project artifacts have been authored yet. Start with the project goal and
principal journeys, then link to canonical artifacts from this guide.

Follow the [editing instructions](../AGENTS.md) and their authoritative type-folder
mapping. New artifacts use `spec/artifacts/<type-folder>/<id>.yaml` relative to the
repository root, one YAML mapping per file with an exact ID-based filename. For
example, `spec/artifacts/requirements/REQ-001.yaml` and
`spec/artifacts/ui-design/UI-001.yaml` illustrate paths without creating live IDs.
Select the folder by current `type`, not ID prefix. Keep provenance in `sources/`,
reading guides in `views/`, and mockups in `mockups/`, separate from `artifacts/`.
