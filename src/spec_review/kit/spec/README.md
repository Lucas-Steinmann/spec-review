# Project specification

Store canonical YAML artifacts in `artifacts/`, provenance in `sources/chat.md`,
and maintained reading guides in `views/`. Read [editing instructions](AGENTS.md)
and the repository's `docs/spec-review/artifact-authoring.md` before authoring.

Validate with `spec-review validate --repo .`. Review with `spec-review --repo .`.
For a custom spec directory, pass `--spec-dir` to both commands.

An empty scaffold records no project requirements. Use
`skills/spec-authoring/SKILL.md` to capture requirements or adopt existing material.
